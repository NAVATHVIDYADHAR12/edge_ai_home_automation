# Edge AI Smart Home

This project runs as a Next.js application and can be deployed directly to Vercel.

## Run locally

Use Node.js 20.9 or newer, then install the locked dependencies and start the development server:

```bash
npm ci
npm run dev
```

Open <http://localhost:3000>.

## Build for production

```bash
npm run build
npm start
```

## Deploy to Vercel

Import this repository in Vercel and keep the detected **Next.js** framework preset and default build settings. Vercel installs the dependencies and runs `npm run build` automatically.
